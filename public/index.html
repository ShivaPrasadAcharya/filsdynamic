WORK DIRECTLY ON THE PAGE

Select. Format. Download.

  1. Open a draft. Its preview appears immediately.
  2. Drag to select a word, line or several paragraphs. A small formatting bar appears. Click a paragraph to format the whole paragraph.
  3. Right-click for the full mouse menu, including Edit paragraph text. Use Ctrl+F to find text, then format the match.
  4. Choose Number or Demote to create linked numbering. Existing typed prefixes are removed when numbering is applied.
  5. Use the right panel for indents, number gaps and paper margins. Changes update automatically.
  6. Copy formatting from one selection, select another, then paste formatting. Download the finished .docx.

DOCX preserves the original package, including tables and images. Legacy DOC imports text; complex RTF layouts may change. Numbering uses Unicode Nepali digits with literal dots. Local fonts can be loaded for text preview.

In normal preview, click to place the caret: Enter splits the paragraph; Backspace at its start joins it to the previous paragraph. Right-click → Edit paragraph text changes wording. Add tab / Remove tab shift indentation; numbered paragraphs of the same level stay aligned. Browser previews may paginate differently from Word.
